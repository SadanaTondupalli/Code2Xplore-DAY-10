# 📊 Data Replication & Corruption Analysis System

## 🔍 Overview

This project simulates a large-scale data replication system using Python. It demonstrates how improper copying techniques can lead to hidden data corruption and affect system reliability. The project also performs data analysis to detect anomalies and predict risks.

---

## ⚙️ Features

* Generation of complex nested data structures
* Implementation of assignment, shallow copy, and deep copy
* Demonstration of hidden corruption using shallow copy
* Custom risk score calculation using mathematical functions
* Data analysis using NumPy and Pandas
* Manual correlation calculation (without using `.corr()`)
* Anomaly detection using statistical thresholds
* Cluster detection of high-risk zones
* Stability index calculation for system evaluation

---

## 🧠 Key Concept

Shallow copy only duplicates the outer structure, while nested elements remain shared. This causes unintended modifications in the original data when changes are made in the copied structure. Deep copy prevents this issue by creating completely independent copies.
